# Internet Doppelganger

## Overview
This project discovers internet profiles and content based on given queries.

## Structure
| File               | Purpose                                 |
| ------------------ | --------------------------------------- |
| `main.py`          | Runs our application                    |
| `search.py`        | Searches the web and discovers profiles |
| `models.py`        | Defines the data structures             |
| `utils.py`         | Helper functions                        |
| `data/`            | Stores collected results                |
| `tests/`           | Tests our code                          |
| `.env`             | Stores API keys                         |
| `requirements.txt` | Python dependencies                     |
| `README.md`        | GitHub documentation                    |
